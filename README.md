# 抖音同步归档 (douyin-sync)

Obsidian 插件：把抖音**收藏 / 点赞 / 作品**自动同步进本地 Vault，让刷过的内容可搜索、可复用。

## 功能

- **定时增量同步**：按可配置间隔自动同步，也可命令/状态栏手动触发。以 `aweme_id` 作为 resourceId 去重，已同步的笔记跳过；进度逐条落盘，中断后下次自动续传（含转写失败重试队列）。
- **收藏类型明确区分**：按 `is_note` / `aweme_type` / 图片字段三重信号把收藏分为**视频**与**图片（图文）**两类，分别处理——视频走「转录 + 抽帧 + 多模态总结」，图文维持「图片下载 + OCR」原逻辑。
- **视频多模态综合总结**：新视频同步时自动——本机 ffmpeg 经播放直链一次拉取（单次网络请求）产出转录用音频与关键帧；关键帧**按时间间隔自适应**（默认每 10 秒一帧，短视频保底 4 帧覆盖全片，上限 100 张，存 `Media/frames/<id>/`）；转录文字 + 关键帧一并交给百炼视觉模型，提示词明确两者互补（转录=口播、帧=画面），生成**层级笔记体摘要**（主题标题 → 引言/核心问题 → 内容分节（含数据公式）→ 总结与意义 → AI 总结，**摘要不含照片**）；全部关键帧收进折叠的「关键帧」块。可在设置关闭或改为手动。
- **云端 ASR 逐字稿**：支持五家：
  - **硅基流动 SenseVoice**（`FunAudioLLM/SenseVoiceSmall`，默认）：本机 ffmpeg 抽取音频后上传，不受抖音 CDN 风控对云端拉取的封锁影响（需本机安装 ffmpeg）
  - 阿里云百炼 **Paraformer** 录音文件识别（`paraformer-v2`，异步任务）
  - 百炼 `qwen3-asr-flash` 多模态直转
  - 火山引擎 录音文件识别大模型
  - 腾讯云 录音文件识别（TC3 签名内置）
  - 逐字稿写入 `> [!quote]- 逐字稿` 折叠 callout，带时间戳分段（SenseVoice 无时间戳，按段落分块）。
- **图文笔记识别**：图文逐张（≤10 张）交给视觉模型，文字写入 `> [!note]- 图片文字` 折叠块；CDN 直连失败自动降级为 base64 上传。
- **收藏夹子目录 + 白名单**：收藏按收藏夹生成子目录；白名单非空时只同步指定收藏夹。
- **AI 自动分类**：OpenAI 兼容接口（默认百炼），从你给定的分类列表中自动归类，写入 YAML `category`。
- **Bases 画廊**（需 Obsidian 1.9+）：自动生成封面墙 / 分类画廊 / 爆款排行（按点赞）/ 最近同步 四个 `.base` 文件。
- **标准 Markdown**：YAML 属性（`douyin_id`/`title`/`author`/`category`/`cover`/`likes`/`stats`/`url`…），封面与图片存 Media 目录；纯文本 + 本地图片，兼容 Obsidian Sync / iCloud / Git。

## 安装

1. 把 `main.js`、`manifest.json`、`styles.css` 三个文件复制到：
   `<你的Vault>/.obsidian/plugins/douyin-sync/`
2. Obsidian 设置 → 第三方插件 → 启用「抖音同步归档」。
3. 从源码构建（如需）：`npm install && npm run build`。

## 配置

### 1. Cookie（必填）

浏览器打开 `douyin.com` 并登录 → `F12` → Network → 点任意一个 `douyin.com` 的请求 → 复制 Request Headers 里**完整的 Cookie 值**，粘贴到插件设置。

> ⚠️ 必须走 Network 面板复制请求头。`document.cookie` 拿不到 `sessionid`（HttpOnly）。Cookie 过期后重新复制即可。

配好后点「测试连接」验证登录态、本地桥接与接口可用性。设置页按钮和命令面板使用同一测试入口，成功提示会明确显示“经本地桥接”。

### 2. 转写 Key（按所选服务商选一）

| 服务商 | Key 获取 | 备注 |
|---|---|---|
| **硅基流动 SenseVoice**（默认） | cloud.siliconflow.cn 创建 API Key | **需本机 ffmpeg**（`winget install "FFmpeg (Gyan.FFmpeg)"`）；本机抽音频后上传，不依赖云端拉取抖音直链 |
| 百炼 Paraformer / qwen3-asr-flash | bailian.console.aliyun.com 开通模型服务，创建 API Key | Paraformer 走异步任务，长视频稳；qwen3-asr-flash 同步返回，快 |
| 火山引擎 | 控制台 - 语音技术 - 应用管理，拿 AppID + Access Token | 开通「录音文件识别大模型」 |
| 腾讯云 | 控制台 - 访问管理 - API 密钥 | 开通「录音文件识别」，按分钟计费 |

**重要风险提示**：除硅基流动外，其余服务都是云端拉取抖音播放直链。抖音 CDN（`douyinvod.com`）对非浏览器来源有风控，**云端拉取可能失败**（前代工具实测百炼直连失败率不低）。失败条目会标记 `transcript_status: failed` 并进入重试队列，下次同步自动续传；连续失败说明抖音 CDN 已封锁该云厂商的抓取，换一家服务商即可。

「每次同步最多转写条数」控制单次 ASR 费用，默认 20，未转写的下次自动续传（也是「补跑旧视频笔记」的单次数量上限）。

### 3. AI Key（分类 / 图片文字识别 / 视频多模态总结）

默认对接百炼 OpenAI 兼容接口（`compatible-mode/v1`），也可填任何兼容端点（硅基流动、OpenAI 等）。需要：文本模型（如 `qwen-plus`）做分类，视觉模型（如 `qwen-vl-plus`）做图片文字，多模态总结模型（默认 `qwen3-vl-plus-2025-12-19`）做视频摘要——百炼各视觉理解模型有新人免费额度（100 万 Token/90 天，跨模型独立），用完可在设置里换仍有额度的模型名；走百炼必须填**带版本号**的模型名（裸名 `qwen3-vl-plus` 免费额度已耗尽会 403）。分类列表每行一个，AI 只会从中选择。

### 4. 视频多模态总结（可选）

- 同步时对新视频自动执行：转录文字 + 关键帧 → 视觉模型 → 结构化层级笔记体摘要（**摘要不含照片**，配图统一在「关键帧」折叠块）；图文类收藏不受影响。
- 关键帧存 `Media/frames/<视频ID>/frame_NN.jpg`，按**抽帧间隔**自适应（默认每 10 秒一帧，短视频保底 4 帧，上限 100 张）。
- 依赖本机 ffmpeg（设置页 ASR 分组可填路径并一键「检测」）。
- **模型三选一（多模态通道与分类通道互相独立）**：
  - 智谱 **GLM-4.6V-Flash**（完全免费）：多模态 Base URL 填 `https://open.bigmodel.cn/api/paas/v4`、API Key 填智谱 Key（bigmodel.cn 注册创建）、模型名 `glm-4.6v-flash`
  - 百炼 qwen3-vl-plus / qwen3.5-omni-plus / qwen-vl-plus 等：多模态 Base URL/Key 留空即复用 AI 通道
  - 提示词已内置实战写法：画面信息挖掘（图表/界面/字幕卡）、ASR 错字校正、空转录重建、诚实标注
- 命令「补跑旧视频笔记（转录+抽帧+摘要）」可对已同步但缺转录、缺摘要、**抽帧间隔与当前设置不一致**或**摘要格式为旧版**的视频批量补跑——已有转录直接复用（不重复计费 ASR）。
- **摘要风格预设**（2026-09-27）：层级笔记体（默认，存量摘要同款）/ 要点速览 / 问答复习体三选一，写入 frontmatter `summary_style`；切换只影响之后新生成的摘要，旧笔记用「补跑旧视频笔记」按新风格重出。
- **Agent 巡检兜底**（可选，需 ZCode 运行）：定时任务每 30 分钟扫描缺摘要/云端失败的视频笔记，自动派 AI 助手亲写（看帧+转录）；每次运行落盘日志 `代码\agent-sweep.log`，日志停更即任务失效，一眼可查。

## 相关笔记互链（2026-09-27 新增）

- 笔记文末自动维护「相关笔记」块：链接**同分类 / 同作者**的已同步笔记（同分类优先于同作者，同分时高赞优先，默认每篇最多 8 条），被链接的笔记也会回链——互链成对建立，构建知识网络。
- 块由隐藏注释标记包裹（`douyin-sync:related:start/end`）、幂等更新：标记之外的内容绝不改动，重复同步不产生重复块。
- 存量笔记用命令「重建相关笔记链接」（或设置页按钮）一次性补齐全库互链；无变化的笔记不写盘。

```
│   ├── <收藏夹名>/2026-09-08 标题 [aweme_id].md
│   └── 未分类/…
├── 点赞/…
├── 作品/…
├── Media/               ← 封面 + 图文图片 + 视频关键帧（可整库同步）
│   ├── cover/<id>.jpg
│   ├── images/<id>/1.jpg …
│   └── frames/<id>/frame_01.jpg …（视频关键帧）
└── Bases/
    ├── 封面墙.base
    ├── 分类画廊.base
    ├── 爆款排行.base
    └── 最近7天.base
```

## 同步机制

- **去重**：`aweme_id` 即 resourceId，已入库的 ID 不再生成笔记。
- **增量**：从第一页向后扫，连续遇到 N 条已同步笔记（默认 100）即提前停止翻页；首次运行自动全量。
- **断点续传**：每处理完一条立即落盘；转写失败的进入持久化队列，下次同步优先重试（消耗转写预算）——重试带指数退避（5 分钟 → 6 小时阶梯），连续 5 次失败转入 dead-letter 不再自动重试，可用命令「查看转写重试队列」检查。
- **白名单语义**：白名单非空且收藏夹接口正常时，只同步白名单收藏夹；接口失败时回退为全量扁平同步（全部进「未分类」）。
- 「重置同步状态」可清空已同步记录（不删笔记），下次重新全量扫描。

## 命令

- `立即同步`（状态栏 / 侧边栏图标也可触发）
- `测试连接`
- `为当前笔记生成 AI 摘要`（视频笔记自动走多模态通道：转录 + 关键帧；图文走文本通道）
- `补跑旧视频笔记（转录+抽帧+摘要）`
- `生成 Bases 画廊`（已存在的不覆盖）
- `查看同步性能画像`（一行画像 + 分阶段 p50/p90 明细，同步收尾自动留档）
- `查看转写重试队列`（队列规模 / 退避中 / 已放弃条目及最后一次错误摘录）
- `重建相关笔记链接`（全量重算文末「相关笔记」互链块，无变化的笔记不写盘）
- `打开管理面板`、`启动桥接进程`、`停止桥接进程`、`重启桥接进程`
- `图片文字识别（选择图片）`

## 开发

- 构建：`npm install && npm run build`（tsc 检查 + esbuild 生产打包，产物 `main.js`）。
- 单测：`npm test`（esbuild 打包 `tests/entry.ts` 聚合的纯函数模块后运行 `tests/*.test.mjs`，无需 Obsidian 环境）。

## 已知限制

1. **请求通道**：抖音 Argus 会拦截 Obsidian/Node 的非页面直连请求。桌面版默认通过仅监听 `127.0.0.1` 的本地桥接，在真实 Chromium 页面上下文中请求抖音；关闭桥接后出现 `HTTP 403 Blocked by ArgusSecurityPlugin` 属于预期风控结果。
2. Bases 的 `now() - 7d` 过滤依赖 Obsidian 版本；若该视图报错，在 Bases 编辑器里打开 `.base` 文件微调即可（数据都在 YAML 属性里，不受影响）。
3. 点赞/作品列表需要从个人页解析自己的 `sec_uid`，登录失效时这两个来源跳过并报错。
4. 私密视频、需要登录才能看的直链，云端 ASR 与本机 ffmpeg 同样拉不到（播放地址过期时插件会经桥接刷新一次）。
5. 视频多模态总结与 SenseVoice 转录依赖本机 ffmpeg；未安装时视频仍会同步（无转录/关键帧），设置页可检测。

## 隐私

Cookie 只存在本机插件配置（`.obsidian/plugins/douyin-sync/data.json`）；封面与图片/关键帧按开关下载到你的 Vault。选择硅基流动 SenseVoice 时，视频会在本机用 ffmpeg 抽取音频并上传至该服务；选择云端 URL 直传服务商时音视频文件不落本机；转写、总结与识别内容会发送给对应云服务商——这是云端方案的固有属性。
